Requirement 15: Printer Sharing with Priority and Scheduling

Step-by-Step Procedure:

  1. Print Server VM: Control Panel → Devices and Printers → Add printer → Local printer (manual settings) → Same port → Same driver
  2. 🥇 TEACHER
    Name: LAB_PRINTER_TEACHER
    Advanced → Security → Add teachers → Print ✓
    Availability: 1:00 PM – 3:00 PM
  3. 🥈 TOP 10
    Name: LAB_PRINTER_TOP10
    Advanced → Security → Add Student1–10 (all sections) → Print ✓
    Availability: 1:00 PM – 3:00 PM
  4. 🥉 GENERAL
    Name: LAB_PRINTER_GENERAL
    Advanced → Security → Add Student11–40 (all sections) → Print ✓
    Availability: 1:00 PM – 3:00 PM
  5. Client VMs: Win+R → \\SERVER-IP → Connect to all 3 printers

Requirement 12: Selective Network & USB Restrictions

Step-by-Step Procedure:

  1. Programming OU GPO: Group Policy Management → Programming OU → Create GPO "Disable USB Access"
  2. NETWORK BLOCK User Config → Admin Templates → System → "All Removable Storage Classes" → Deny all access → Network → "Prohibit installation of network adapters" → Enabled
  3. USB BLOCK Computer Config → Admin Templates → System → Removable Storage Access → All Removable Storage: Deny all access → Enabled
  4. Link GPO: Programming OU → Link "Disable USB Access" → Teachers OUs: NO GPO LINK
  5. TEST: Programming student → No internet/USB | Other students → Full access | Teachers → Full access ✅

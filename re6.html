Requirement 6: Workstation Assignment per Student

Manual Verification Steps:

  1. Test login on assigned PC
  2. Try wrong PC → should fail
  3. Check ADUC "Log on to" settings
  4. Combine with logon hours restriction

🚀 PowerShell Automation (Run on DC):

          # Open PowerShell as Domain Admin
          Import-Module ActiveDirectory

          # COMTECH1A: Student → Workstation Mapping
          $workstations = @{
              "student_comtech1a_01" = "PC-COMTECH1A-01$"
              "student_comtech_02" = "PC-COMTECH1A-02$"
              "student_comtech_03" = "PC-COMTECH1A-03$"
              # Add all students...
          }

          foreach ($student in $workstations.Keys) {
              Set-ADUser $student -LogonWorkstations $workstations[$student]
              Write-Host "✅ $student → $($workstations[$student])" -ForegroundColor Green
          }

          Write-Host "`n🔍 VERIFY: Open ADUC → Check User Properties → Account tab → Log on to..." -ForegroundColor Yellow

Requirement 9: Block USB Storage for Students

Manual GPO Method:

  1. GPMC → Create GPO "BLOCK_USB_STUDENTS" → Link to All Student OUs
  2. Computer Config → Policies → Admin Templates → System → Removable Storage Access
  3. Enable "All Removable Storage classes: Deny all access"
  4. TEST: Student PC → USB drive = Access Denied | Teacher PC = USB works

Verification:

  • ❌ Student: USB = "Access Denied" | File Explorer = No removable drives
  • ✅ Teacher: Full USB read/write access confirmed

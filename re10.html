Requirement 10: Remove Shutdown/Restart for Students

Manual GPO Method

  1. Open Group Policy Management → Right-click Student OU → Create/Edit GPO BLOCK_SHUTDOWN_STUDENTS
  2. Navigate to User Config → Policies → Administrative Templates → Start Menu and Taskbar
  3. Enable "Remove and prevent access to the Shut Down, Restart, Sleep, and Hibernate commands"
  4. Link the GPO to all Student OUs, then run gpupdate /force

PowerShell Automation

Import-Module GroupPolicy

$gpoName = "BLOCK_SHUTDOWN_STUDENTS"

New-GPO -Name $gpoName

Set-GPRegistryValue -Name $gpoName `
  -Key "HKLM\Software\Microsoft\Windows\CurrentVersion\Policies\System" `
  -ValueName "ShutdownWithoutLogon" `
  -Type DWord -Value 0

$studentOUs = @(
  "OU=COMTECH1A,DC=group2,DC=local",
  "OU=COMTECH1B,DC=group2,DC=local",
  "OU=COMTECH2A,DC=group2,DC=local",
  "OU=COMTECH2B,DC=group2,DC=local",
  "OU=COMTECH3A,DC=group2,DC=local",
  "OU=COMTECH3B,DC=group2,DC=local",
  "OU=COMTECH4A,DC=group2,DC=local",
  "OU=COMTECH4B,DC=group2,DC=local"
)

foreach ($ou in $studentOUs) {
  New-GPLink -Name $gpoName -Target $ou -Enforced Yes
}

Verification

  • ✗
    Student Account Start Menu → Shutdown/Restart options are hidden. Ctrl+Alt+Del → Power button is removed.
  • ✓
    Teacher Account Full Shutdown and Restart access is confirmed — GPO does not apply to Teacher OU.

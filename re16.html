Requirement 16: Remote OS Installation

Step-by-Step Procedure:

  1. Server Manager → Manage → Add Roles and Features → Next → Next → Next → Windows Deployment Services → Next
    ✔ Deployment Server  ✔ Transport Server → [Install] → Wait → [Close]
  2. Tools → Windows Deployment Services
    ✅ Verify: Install Images → Boot Images → Pending Devices
  3. Right-click [Server Name] → Configure Server → Next → D:\RemoteInstall → Next
    ✔ Respond to all client computers → Next → Next → Finish
  4. Mount Windows ISO → D:\sources\boot.wim
    Right-click Boot Images → Add Boot Image → D:\sources\boot.wim → "Windows 10/11 Boot Image" → Next → Next → Finish
